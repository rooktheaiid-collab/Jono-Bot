INSTALL JONO BOT DI MACBOOK

1. Ekstrak arsip ini (klik dua kali). Akan muncul folder Jono-Bot.
2. Buka Terminal, lalu: cd ~/Downloads/Jono-Bot   (sesuaikan lokasi folder)
3. Jalankan: bash install_mac.sh
4. Saat diminta, tempel KODE AKSES (token panjang berawalan JB1.). Setelah itu boleh isi key Gemini, atau Enter untuk lewati dan isi nanti di tab Integrasi.
5. Tunggu sampai muncul "Jalan: http://127.0.0.1:8780/". Buka alamat itu di Safari atau Chrome dan izinkan mikrofon.
6. Buka tab Integrasi (ikon petir), masukkan KODE ADMIN (terpisah dari kode akses).

Syarat: macOS dengan Python 3.9 atau lebih baru dan Xcode Command Line Tools (kalau belum ada, jalankan xcode-select --install lalu ulangi).
Autostart: layanan launchd id.reza.jonobot menyala otomatis saat login. Hapus dengan: bash install_mac.sh --uninstall
Log: ~/JonoBot/logs/
